# AXON auth emails

Templates: `supabase/templates/*.html` (sent) + `*.txt` (plain-text twin for a
custom SMTP provider / send-email hook). Generated by
`node scripts/build-email-templates.mjs`; edit the script, not the output.
Subjects live in `supabase/templates/subjects.json` and `supabase/config.toml`.

Covered: confirmation (sign-up), magic_link, recovery (password reset),
email_change, invite, reauthentication (code).

Style: matte black card, gold accent + CTA, titanium body text, single column,
max 520px, table layout with inline styles (Gmail/Outlook/Apple Mail safe),
dark color-scheme, hidden preheader, raw link fallback under every button.

## Sender: no-reply@axon-memory.com (custom SMTP)

Supabase's built-in mailer sends from noreply@mail.app.supabase.io, is rate
limited (a few mails/hour) and is meant for testing only. Production needs a
custom SMTP provider. Recommended: Resend (free tier, 3k mails/month).

1. Resend: add domain `axon-memory.com` (region EU), copy the DNS records it
   shows (DKIM TXT `resend._domainkey`, SPF/MX on the `send` subdomain), add
   them in Cloudflare DNS (DNS only, not proxied), then verify.
2. Create an API key with "Sending access".
3. Supabase Dashboard -> Authentication -> SMTP settings: enable custom SMTP,
   host `smtp.resend.com`, port 465, user `resend`, password = API key,
   sender `no-reply@axon-memory.com`, name `AXON`.
4. Authentication -> Email Templates: for each template paste the subject and
   the HTML from this folder (or `supabase config push`).
5. Optional DMARC: TXT `_dmarc.axon-memory.com` = `v=DMARC1; p=none;`.
